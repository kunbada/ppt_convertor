PPT 노트 도구

발표자 노트 삽입·추출, 노트 음성 변환, PDF → PPT 변환. 파일은 이 브라우저 안에서만 처리됩니다.

노트 삽입 · 텍스트 → PPT

노트 파일(.md / .txt)의 내용을 PPTX 각 슬라이드의 발표자 노트에 순서대로 넣고, 새 파일로 내려받습니다. 원본은 바뀌지 않습니다.

슬라이드 노트 파일
원본 PPTX 파일
브라우저의 기본 다운로드 폴더에 저장됩니다.

노트 추출 · PPT → 텍스트

PPTX의 발표자 노트를 꺼내 텍스트 파일로 내려받습니다. 결과는 노트 삽입·음성 변환 탭에서 바로 이어 쓸 수 있습니다.

PPTX 파일
슬라이드 구분 방식

음성 변환 · 텍스트 → MP3

노트를 Azure AI Speech로 읽어 슬라이드별 MP3를 만듭니다. 무료(F0) 티어는 매달 뉴럴 TTS 50만 자까지 과금되지 않습니다.

노트 소스 (.md / .txt)
🔐 키 보관함 (암호화 저장 · 불러오기)
키·리전·음성을 비밀번호로 AES-256 암호화해 이 브라우저에만 저장합니다. 서버로 전송되지 않으며, 비밀번호를 잊으면 복구할 수 없습니다. 다른 PC에서는 '파일로 내보내기' → '파일 가져오기'를 쓰세요. 공개 저장소에 올리지 마세요.
리전은 Azure Portal에서 만든 Speech 리소스의 지역입니다. 로케일을 비우면 전체 언어를 불러옵니다.
목록에서 고르거나, 음성 이름을 알고 있으면 직접 입력해도 됩니다.

PDF → PPT · 이미지 변환

PDF 각 페이지를 고해상도 JPG로 렌더링해 슬라이드 전체에 꽉 채운 PPTX를 만듭니다. 이미지 방식이라 폰트와 레이아웃이 깨지지 않습니다.

변환할 PDF 파일
DPI가 높을수록 화질은 좋아지지만 변환 시간과 파일 용량이 늘어납니다. 권장 300.
PDF 파일을 선택하세요.
진행 로그

    

  

  
인터넷 연결이 필요합니다 (라이브러리 로딩, Azure 음성 합성). PPT → PDF/이미지 변환은 브라우저에서 정확히 할 수 없어 로컬 스크립트(ppt_export.py)를 사용합니다. PPTX·PDF 파일 내용은 외부로 전송되지 않으며, 음성 변환 시 노트 텍스트만 Azure로 전송됩니다.
